# PixLab

PixLab 是一个以 C 语言为核心的 BMP 图像处理学习项目，目标是从“内存中的图像处理”逐步扩展到“真实 BMP 文件的读取、处理和输出”。

这个项目的重点不在于做一个完美的工业级图像库，而在于通过小而清晰的里程碑，逐步掌握图像处理的核心概念：

- 像素布局
- 通道与灰度计算
- 卷积和邻域操作
- BMP 文件格式
- 图片输入输出
- 命令行工具结构

---

## 项目目标

### 目前阶段

项目已经完成基础图像算子和图像容器，正在向真实 BMP 文件处理方向推进。

目标功能示例：

```bash
pixlab input.bmp output.bmp gray
pixlab input.bmp output.bmp invert
pixlab input.bmp output.bmp blur
pixlab input.bmp output.bmp sobel
```

### 预期能力

- 读取 BMP 文件
- 提取图片宽高、位深和像素数据
- 对图像执行灰度化、反色、模糊、边缘检测
- 输出处理后的 BMP 文件
- 提供简单命令行接口

## 设计思路

这个项目分成两大部分：

1. 图像算法层
   - 关注像素如何计算
   - 关注卷积、邻域、阈值与灰度值

2. 文件格式层
   - 关注 BMP 头部、数据布局、字节顺序
   - 关注真实图片如何被读入和写出

这两部分是分开学习的，避免把“算法错误”和“格式错误”混在一起，导致排错困难。

---

## 关键学习点

### 1. 图像作为一维缓冲

图像可以看作一个连续数组。访问某个像素时，需要通过：

```c
row * width + col
```

这样的地址换算来定位数据。

### 2. 邻域操作

均值模糊和 Sobel 边缘检测都依赖邻域卷积。关键在于：

- 边界处理
- clamp / clip
- 绝对值和累加

### 3. BMP 的真实复杂性

BMP 看似简单，但它涉及：

- 头文件结构
- BGR 与 RGB 的顺序差异
- 每行末尾 padding
- 图像可能自底向上存储
- 位深和压缩方式判断
